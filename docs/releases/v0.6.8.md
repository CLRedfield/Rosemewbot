# Rosemewbot v0.6.8

发布日期：2026-11-14。

## SnowLuma 下载与自动切换

修复桌面组件下载没有沿用 Windows 系统代理的问题。旧下载器使用 Node 直连，在需要系统代理的网络中，即使浏览器能打开归档文件，应用也可能下载失败。新版的来源检测和文件下载统一通过 Electron 网络通道，自动使用 Windows 系统代理与 PAC 配置。

- SnowLuma 配置同版本官方主地址与 [XingYunStar 历史归档备用地址](https://github.com/XingYunStar/snowluma/releases/tag/v2.4.2)。主源检测失败时自动使用备用源，无需手动复制链接或再次点击。
- 即使主源检测通过、正式下载时才报错，也会自动切换；下载卡住、断开或校验失败同样会尝试其他来源。
- 修复失败源要求等待重试时，备用源也被迫等待的问题。备用源首次尝试立即接续；重复尝试失败源仍保留退避。
- 来源检测最长 5 秒，传输连续 15 秒没有收到数据时切换；完整传输仍允许最多 15 分钟。
- 保留固定 SHA-256 校验、本地缓存复用和失败临时文件清理。下载页显示当前来源及自动切换状态。

SnowLuma 仍固定为 v2.4.2，不改变已有账号与配置。本安装包不内置 SnowLuma 二进制；归档来自第三方，不代表原上游恢复维护。

## 升级方法

1. 退出旧版，在原位置安装 v0.6.8。仅点击旧版中的“更新组件”不会升级 Rosemewbot 自身的下载器。
2. 如果使用代理软件，开启其“系统代理”，确保可以访问 GitHub 发布附件。
3. 此前准备失败的用户重新点击“一键完成首次准备”；已有组件需要重新下载时点击“修复组件”。下载失败会自动尝试备用源，原数据目录继续使用。
