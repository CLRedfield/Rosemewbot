# Rosemewbot v0.6.7

发布日期：2026-11-13。

## 修复 SnowLuma 无法下载

旧版锁定的 SnowLuma v2.1.0 官方下载地址已返回 HTTP 404，重复点击准备或切换网络无法恢复该文件。本版本将 SnowLuma 更新为 v2.4.2，使用 [XingYunStar 保存的历史发行包](https://github.com/XingYunStar/snowluma/releases/tag/v2.4.2)，保留同版本官方地址作为备用。

- 下载前检查来源，优先使用可达来源；进度显示版本、已下载大小、来源与重试次数。
- 修复来源返回 404/410 后可能跳过下一个备用源的问题；失效地址不再反复重试。
- 所有来源使用同一个固定 SHA-256 校验。通过校验的本地缓存可直接复用，校验失败或下载中断的临时文件会被清理。
- 下载最终失败时保留各来源的错误，提示检查发布附件网络访问或 Rosemewbot 新版本。
- 保留既有 AstrBot 配置与 SnowLuma config/data/logs；组件更新继续使用升级前快照和失败回滚。

SnowLuma 为第三方历史归档，不代表原上游恢复公开分发或维护。本应用安装包不内置 SnowLuma 二进制，首次准备仍需要能访问 GitHub 发布附件。

## 升级步骤

1. 退出 Rosemewbot，在原安装位置安装 v0.6.7。
2. 此前首次准备失败的用户，重新点击“一键完成首次准备”；已有可用组件的用户，点击“更新组件”。
3. 下载完成后启动机器人，按 SnowLuma 后台提示完成必要的首次设置，并确认所选 QQ 与 OneBot 状态。

不需要删除数据目录或重新填写 AstrBot 模型配置。请勿手动删除 `Rosemewbot-data`。
